BookShelf · Web Security Labs

Навчальний REST-застосунок: бібліотека книг, ролі та аудит змін.

  • /basic/books — Basic Auth + CSRF
  • /auth/token — отримання JWT (POST)
  • /api/books — CRUD через Bearer JWT
  • /api/audit — журнал змін для ADMIN

Ролі: READER читає, EDITOR створює та редагує, ADMIN також видаляє і переглядає аудит.

Готові запити й інструкції здачі розміщені у папках requests та docs проєкту.
